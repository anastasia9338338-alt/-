# Astral v5.09

Обновление присланного `astral-v5.08.zip` для Fling Things and People (`PlaceId=6961824067`). Для запуска достаточно одного `astral.lua`: все модули встроены. Отдельная сборка и новые зависимости для игры не нужны.

## Изменения

- **Anti Kick:** общий поиск текущего корня персонажа, включая `realHrp`, `saviHRP` и `HumanoidRootPart`; поиск настоящих `FirePlayerPart` / `RagdollTouchedHitbox` на этих корнях. Устаревший корень после респавна отклоняется. Состояние переключателя и настройки предмета явно применяются при запуске и загрузке конфига, даже если библиотека подавляет callbacks. Ошибки подготовки предмета освобождают запрос и показываются в диагностике.
- **Settings игрового магазина:** удалено изменение размеров, позиций, масштаба и элементов цветового выбора. При входе возвращаются сохранённые игровые свойства, отключаются наблюдатели геометрии, обработка карточек и обновление декоративных иконок; дополнительная кнопка быстрых игрушек скрывается. При возврате к товарам оформление строится заново.
- **Your Toys:** одинаковые с Toy Shop размеры карточек, область картинки и место для подписей. Для совпадающих внутренних имён используются изображения, прямоугольники атласа и порядок карточек из доступного Toy Shop. Пока магазин не предоставил карточку, используется существующий каталог изображений; неизвестные предметы сохраняют доступную нативную картинку. Внешняя кнопка со звездой избранного не выбирается вместо изображения игрушки. При наличии картинки соответствующее 3D-превью скрывается.
- **Переключатели:** скруглённые квадраты с радиусом 5 px; скругление окна больше не превращает их в круги.
- **Packets:** текст `Packet-Lag Server` и `Send One Packet` использует обычный цвет темы.
- **Иконки вкладок:** новый набор силуэтных иконок по назначению каждой вкладки, включая Aim, Fun и GUI. Они рисуются локальными элементами интерфейса.
- **Main:** Profile с аватаром и быстрыми действиями; Stats с игроками, FPS, ping и временем сессии; Info с данными игрока и версии; сворачиваемые Contributors. Динамические подписи обновляются раз в секунду при видимой вкладке. Прежние Tools, Teleport Menu и Desync Menu находятся в Player, Barrier — в Combat.
- **Defense:** группы Grab Protection, Kick Protection, Network & Performance, Hazard Protection, Recovery, World Protection и Blobman Protection. Отдельной видимой группы Config нет. Её настройки доступны через шестерёнки соответствующих переключателей; дополнительные встроенные настройки также перенесены к своим функциям. Идентификаторы сохранённых настроек сохранены.

## Запуск

1. Выгрузи предыдущую версию через **Settings → Unload**.
2. Выполни новый `astral.lua` прежним способом.
3. Anti Kick находится в **Defense → Kick Protection**; предмет, размещение и диагностика — в его шестерёнке.

Требования исполнителя, включая `loadstring`, `getgenv`, `setfenv` и игровые API, остаются требованиями исходного проекта.

## Наблюдаемые проверки

Luau 0.747 скомпилировал полный файл и **101 исполняемый встроенный модуль**. Все буквальные зависимости присутствуют. `Notices` содержит лицензии и не исполняется.

Новые изолированные проверки:

- 14 проверок Anti Kick: переименование корня, настоящий предмет и имитация подтверждения привязки, повторное использование, респавн, устаревший корень, отсутствие хитбокса, отмена ожидающего запроса, ошибка подготовки, применение сохранённого состояния без UI-callbacks.
- 11 проверок магазина сверх 14 прежних: восстановление игровых свойств и отключение наблюдателей, уже поставленный в очередь repair после восстановления, 600 изменений положения цветового выбора без принудительных исправлений и перераскладки; изображения и порядок из Toy Shop, одинаковые размеры карточек, скрытие старого превью.
- Прежние проверки спавна и Gucci/расписания также прошли. Их исходные журналы сохранены в `CHECKS.txt`; показатели расписания не измеряют серверные события.

Регрессия поиска хитбокса с `saviHRP` отдельно воспроизведена на исходном модуле v5.08: новый тест на нём завершается ошибкой, а на обновлённом модуле проходит.

**Roblox и исполнитель пользователя здесь недоступны. Фактический спавн/серверная привязка, внешний вид в игре и FPS в магазине не проверены.** Тесты используют заменители игровых API. Точное значение `PlaceVersion` и возможные изменения серверных моделей неизвестны; адреса и смещения не добавлялись.

Короткая игровая проверка: включить Anti Kick и посмотреть его диагностику, дождаться предмета, выполнить респавн; несколько раз перейти Your Toys → Toy Shop → Settings и подвигать цветовой выбор, сравнив FPS и неподвижность меню. Для отсутствующей карточки Toy Shop проверить сопоставление после её появления. Если предмет не появился, текст диагностики укажет, отсутствует ли хитбокс, блокирует ли спавн чужой участок или не подтверждён запрос.

## Повторить локальные проверки

Нужны Python 3.10+ (стандартная библиотека) и Luau **0.747**:
https://github.com/luau-lang/luau/releases/tag/0.747

Из распакованного архива:

```sh
python3 tests/verify.py --luau /path/to/luau --compile /path/to/luau-compile
```

Windows:

```powershell
python tests/verify.py --luau C:/tools/luau-0.747/luau.exe --compile C:/tools/luau-0.747/luau-compile.exe
```

Проверка сама извлекает модули из распространяемого `astral.lua` во временную папку; игровой скрипт целиком не запускает.

`changes-from-v5.08.patch` — изменения распространяемого файла относительно присланного архива. Для отката выгрузи обновление и используй исходный архив v5.08.

## Проверка перед публикацией в репозиторий

Скомпилированы также встроенный `embeddedGameplay` и 101 модуль; выполнены 24 source-derived проверки из `tools/regressions.py`. Просмотрены отчёты `luau-analyze`; его сообщения об отсутствующих Roblox/executor API не считаются чистой проверкой типов.

Команда `python tools/verify.py --luau-dir ...` была запущена на точном новом скрипте с соответствующим ZIP. Она останавливается в `check_transfer_preservation.py`: исторический список допустимых изменений к базе v5.00 не допускает изменённый `ExtraFeatures`. Отдельный запуск старых feature harnesses останавливается на `defense_workers`: его mock не содержит новой группы `defense.Hazards`. Эти проверки не отмечены как пройденные. Профильные проверки спавна, Anti Kick и магазина из архива v5.09 прошли. Версия публикуется отдельными файлами без замены прежнего `astral.lua`.
