GUIAppearance.luau adds the final GUI tab with two native image previews, URL inputs, per-layer color/opacity controls and a normalized eight-piece border. The center is never drawn. Theme matching reuses the native BodyTopColor/BodyBottomColor gradient across the border pieces and follows the theme registry. Existing Library, UIStyle, UIMotion, Watermark and Icons are unchanged from v4.80. Empty URLs leave the reference gray GUI unchanged. The native UI harness covers resized/small windows, retained asset-file lifetime, old request cancellation, preview updates, config restoration and cleanup.
