# Проверка принимающего аккаунта

[Скачать hit_probe.lua в ZIP](https://github.com/anastasia9338338-alt/-/raw/refs/heads/main/diagnostics/hit_probe.zip).

1. На принимающем втором аккаунте запустите `hit_probe.lua` до проверки палетки. Astral на этом аккаунте не нужен.
2. На первом аккаунте запустите новую версию Astral и воспроизведите проблему.
3. На втором аккаунте нажмите **Copy report**. На первом доступна **Copy Kick Info** в разделе кика. Сохраните оба отчёта вместе с видео.
4. **Close** закрывает окно и отключает наблюдение. Повторный запуск заменяет старый экземпляр.

Скрипт создаёт только своё окно и читает `Humanoid.Ragdolled`, `CurrentCamera.Blur` и параметры `RagdollTouchedHitbox`. Он не вызывает игровые remotes, не меняет камеру, эффекты, персонажа, хитбоксы или физику.

Изменения наблюдаются по сигналам; поиск новых объектов и обновление окна — 10 раз в секунду. Исходное значение является базовым состоянием, а не попаданием. Постоянное `Ragdolled=true` или активный blur не позволяет посчитать отдельные удары. Краткие изменения blur при отложенных сигналах и события до обнаружения объекта могут быть пропущены. Наблюдается только эффект с именем `Blur` непосредственно в текущей камере.

Отчёт отражает наблюдаемые локальные состояния. Он не является подтверждением серверного попадания, причины размытия или успешного кика.
