# Клёвый Улов — Unity WebGL

Браузерный 3D-симулятор рыбалки. Тренируешь силу заброса, закидываешь удочку с пирса по водному каналу через 12 локаций и ловишь рыб и морских монстров семи редкостей. Улов выпускаешь в аквариум ради пассивного дохода, покупаешь удочки, наживку, тренажёры и улучшения.

Название, модели, интерфейс, звуки и музыка собственные. Все модели собираются кодом из примитивов, звуки и музыка синтезируются при запуске, иконки рисуются процедурно. Шрифты Russo One и PT Sans распространяются по лицензии SIL OFL, файлы лицензий лежат рядом со шрифтами.

Папка проекта и пространства имён в коде по-прежнему называются `ZooThrow`: это внутреннее имя, игроку оно не показывается.

## Быстрый старт

1. Установи **Unity 6.0 LTS** (6000.0.x) с модулем **Web Build Support**.
2. Unity Hub → **Add → Add project from disk** → выбери папку `ZooThrow`. Можно и иначе: создать проект из шаблона **Universal 3D** и скопировать в него `Assets/ZooThrow` и `Assets/WebGLTemplates`.
3. После первой компиляции запустится автонастройка. Вручную она вызывается так: **ZooThrow → 1. Настроить проект**. Что она делает:
   - импортирует TMP Essential Resources;
   - создаёт URP Asset, если его ещё нет;
   - делает кириллические TMP-шрифты;
   - раскладывает все данные (локации, существа, удочки, наживка, тренажёры, улучшения, баланс) по ScriptableObject в `Assets/ZooThrow/ScriptableObjects`;
   - создаёт сцену `Assets/ZooThrow/Scenes/ZooThrow.unity`;
   - настраивает WebGL.
4. Открой сцену `ZooThrow` и нажми **Play**.

Если ты открывал прошлую версию проекта (с бросанием еды), выполни **ZooThrow → Пересоздать данные**. Иначе останутся старые ScriptableObject-ассеты. Сохранение прототипа не переносится: у новой версии свой ключ сохранения.

## Сборка WebGL

- Из редактора: **ZooThrow → 3. Собрать WebGL**. Результат появится в `Builds/WebGL`.
- Из командной строки:
  ```
  Unity -batchmode -quit -projectPath <путь>/ZooThrow -buildTarget WebGL -executeMethod ZooThrow.EditorTools.ZooThrowSetup.BuildWebGLBatch -logFile build.log
  ```
- Локальный запуск: `cd Builds/WebGL && python -m http.server 8080`, затем открой `http://localhost:8080`. Двойной клик по `index.html` не сработает.

## Игровой цикл

Тренировка на турнике → заброс с мини-игрой точности → поплавок летит по дуге, за ним следит камера → приводнение в локации → поклёвка → существо выпрыгивает из воды → аквариум → доход → покупки → заброс дальше → новая локация.

- **Дальность заброса** = база + сила + бонус удочки + бонус наживки + бонус точности. Бонус точности равен (множитель − 1) × (всё остальное), поэтому у слабого заброса он отрицательный. Оценки: «Слабый», «Хороший», «Отличный», «PERFECT CAST!».
- **Удача** = наживка × удочка × улучшение «Удача рыбака»; PERFECT даёт ещё ×1.3. Удача сдвигает улов к редким существам.
- **Магазин удочек (B):** 9 удочек, от бамбуковой до «Легенды» (+400 м). Удочка в руке всегда та, что выбрана.
- **Магазин наживки (N):** 9 видов наживки, от червяка до драконьей приманки.
- **12 локаций:**

  | Локация | Дальность |
  |---|---|
  | Тихий пруд | 0–60 м |
  | Горная река | 60–110 м |
  | Зеркальное озеро | 110–160 м |
  | Туманное болото | 160–230 м |
  | Мангровые заросли | 230–310 м |
  | Коралловый риф | 310–400 м |
  | Открытое море | 400–500 м |
  | Ледяной океан | 500–610 м |
  | Глубоководная впадина | 610–730 м |
  | Вулканический разлом | 730–860 м |
  | Затонувшая Атлантида | 860–1010 м |
  | Бездна | 1010–1200 м |

- **81 существо:** обычные рыбы и редкие большие монстры. Среди монстров:
  - Лотосовый змей, Речной дракон, Озёрное чудище, Болотная гидра;
  - Левиафан, Ледяной змей, Морозный дракон, Кракен;
  - Лавовый дракон, Морской царь, Кит Посейдона;
  - Дракон Бездны, Древний Левиафан.

  Секретные существа: Хрустальный карп, Радужная рыба, Золотой дракон, Титан Пустоты. Шанс в коллекции и на экране награды показывается в виде «1 из N»: у мифических при старте около 1 из 2000, у секретных — 1 из 50 000.
- **Аквариум:** 4 места на старте, до 12 через улучшения.
- **Офлайн-доход** и **сохранение** с контрольной суммой, резервной копией и починкой данных.

## Настройка баланса

Все числа лежат в ScriptableObject в `Assets/ZooThrow/ScriptableObjects`. Правь их в инспекторе, код менять не нужно. **ZooThrow → Пересоздать данные** возвращает значения из `DefaultContent.cs`. ID существ, удочек и наживки записаны в сохранения, поэтому у существующих записей их не меняй.

