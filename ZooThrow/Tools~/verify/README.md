# Проверки вне Unity

Папки с `~` в конце Unity не импортирует, поэтому здесь лежат инструменты, которые не попадают в игру.

- `sim/` — баланс и чистая логика. Собирается с **тем же** кодом игры (`ThrowMath`, `AnimalRoller`, `Progression`, `NumberFormat`, `SaveValidator`, `DefaultContent`) и с минимальной заглушкой `FakeUnity.cs`. Проверяет: валидность контента, сумму шансов = 1 в каждом биоме и при разной удаче, частоты выпадений против формулы, пороги точности, формулу дальности, мини-игру, опыт, форматирование денег, ремонт битого сохранения, а также прогоняет бота-игрока (первое животное, первая покупка, время открытия биомов).
  ```
  dotnet run --project sim -c Release
  ```
- `vis/` — запускает настоящие генераторы моделей (животные, еда, тренажёры, декор) и иконок на управляемой копии математики Unity и сохраняет геометрию в JSON; `render.py` (numpy + Pillow) растеризует её в превью-листы.
  ```
  dotnet run --project vis -c Release -- out && python3 vis/render.py out
  ```
  На превью пурпурным отмечены видимые обратные грани. На крыльях это ожидаемо: левое крыло зеркалится отрицательным масштабом, Unity в этом случае сама инвертирует отсечение, а превью — нет.
- `stubs/Stubs.cs` — заглушки API Input System и URP только для проверки компиляции скриптов против референсных сборок UnityEngine/UnityEditor вне редактора.
