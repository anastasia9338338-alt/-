# Astral v4.94

Готовый скрипт находится в `astral.zip`; внутри один `astral.lua`. Перед заменой выполнить Settings → Unload astral, затем запустить новый Lua.

Основной кик переведён с физического sweep на подготовленную вращающуюся палетку и касание HumanoidRootPart из приложенного TheWorst. Faster/Normal и Loop MS сохранены. Ownership refresh больше не ждёт, пока цель достигнет точки BodyPosition или доска пролетит через hitbox. Возвращено обнуление скорости принадлежащих клиенту частей перед физическим шагом; цель одиночного кика остаётся прямо над игроком. Native joints, масса персонажа и текущий ragdoll rig сохраняются. Для source hold используется BodyPosition с D=100 без дополнительного BodyGyro.

Палетку выдаёт один общий PalletSupply для предварительной подготовки и остальных ragdoll функций. Он отправляет один SpawnToy RPC, сохраняет модель до появления SoundPart/Main, не считает timeout новым запросом и отслеживает поздний результат после отмены/выгрузки. Глобальная блокировка магазина освобождается по таймауту даже при зависшем RPC. Явный отказ сервера допускает повтор; неизвестный результат остаётся ожидающим, чтобы не плодить доски.

Для source контакта подготовлены вращение с реальным MaxTorque, SoundPart 6×2×6 и отдельный подъёмный mover. Доска размещается на Y=1000 с целью mover Y=10000; она больше не паркуется рядом с игроком с выключенной силой. Касания идут парами begin/end, включая остановку и смену персонажа; исходный CanTouch принимающей части восстанавливается. Преднамеренное удаление PartOwner при target Grab не заставляет каждый раз повторно создавать или захватывать уже подготовленную палетку. Если native touch API отсутствует, сохранён прежний one-shot ragdoll fallback.

Настройки Single Hit Pause / Burst Hits / After Burst Pause удалены: новая основная схема их не использует. Тема, магазин, иконки, watermark, PCLD и остальные функции этой правкой не менялись.

Проверка включает компиляцию точной сборки и embedded gameplay, зависимости/API, соответствие ZIP и регрессии с engine mocks: порядок Faster/Normal, задержки Loop MS, реальные аргументы Main, ownership, streaming, параллельные запросы, отмена, respawn и unload. Это не живой Roblox: успешный серверный кик, его время и принятие контактов в игре здесь не измерялись. Реплицируемую палетку нельзя сделать невидимой/недоступной другим игрокам одним LocalTransparencyModifier; в этой версии она убрана из обычной зоны досягаемости, серверная блокировка чужого grab не заявляется.
