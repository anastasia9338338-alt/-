# Astral v4.87

[Скачать ZIP с Lua](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.87-menu-ragdoll/astral.zip?download=1) · [Lua отдельно](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.87-menu-ragdoll/astral.lua?download=1)

Сначала **Settings → Unload astral**, затем запустите новый Lua. Оформление игрового меню включается в **GUI → Магазин по референсу**. Главный интерфейс Astral, его иконки, прозрачная серая тема, ватермарк и Avatar ПЦЛД сохранены.

Игровое меню использует общую оболочку для всех страниц TabContents, включая покупку игрушек, инвентарь, удаление игрушек и Settings. Размер окна сохранён как в v4.86, согласно последнему уточнению; боковая панель и область предметов имеют одинаковую высоту, изображения отступают от закруглённой границы. Звёзды на предметах скрыты. При смене страницы предыдущие изменения восстанавливаются перед применением нового профиля. Цены и названия карточек получают отдельные ограниченные области текста; настройки сохраняют пропорции штатных контролов и исходные обработчики.

Скрытие старых заголовков и лимита учитывает локализованные подписи и обводку текста, а также связанные элементы MenuGui вне Menu. Новое оформление не добавляет поддельные игровые страницы и сохраняет существующие кнопки, избранное, изображения и камеры превью.

Вкладка с часами содержит быстрый спавн: «Добавить предмет» открывает список из собственного нативного инвентаря. Под выбранной иконкой находится поле бинда такой же ширины. Нажатие на поле назначает клавишу; Backspace/Delete или ПКМ очищают бинд, ПКМ по картинке удаляет предмет из списка. Клавиша и нажатие на иконку вызывают существующий SpawnToy с проверкой доступности спавна. Выбор и бинды участвуют в обычном сохранении конфигурации Astral. Ввод текста и обработанные игрой нажатия не спавнят предметы.

Повторные удары палетки используют существующую игровую область касания и физический проход через неё. Непрерывный путь отделён от исходной одноразовой операции; сохраняются владение, границы физических кадров, отмена, изоляция сборки и восстановление CanQuery. Счётчики пересечения на клиенте не являются серверными подтверждениями кика.

Повторная полная переразметка при добавлении служебных элементов устранена; неизменённая страница и обновления счётчика не перестраивают весь инвентарь.

Проверки выполняются на точных Lua и ZIP: компиляция, анализ диагностик, переходы между страницами, карточки с ценами, настройки, восстановление, движение Box/Avatar, физические кадры палетки и отмена. Это CLI-проверки и имитация движка. Живой Roblox, визуальное совпадение по пикселям и серверное время кика здесь не проверялись; кик за 7 секунд не подтверждён.

```sh
python -m pip install 'Pillow>=10.2'
python tools/verify.py --luau-dir /path/to/luau/tools --analysis-dir /path/to/logs
```

Лицензии и исходные уведомления сохранены в Lua, включая кодеки [Picguin](https://github.com/wizevaxel/picguin/tree/c9c10f5639720d7dedc7955052026d6636b3d5b0) и [lua-img-ascii](https://github.com/tiberium/lua-img-ascii/tree/822915dd0cc1d72280a018dde0a622fe59fa696b).
