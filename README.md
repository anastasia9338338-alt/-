# Astral v4.91 — восстановление Unstick

[Скачать ZIP с Lua](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.91-unstick-restore/astral.zip?download=1) · [Lua отдельно](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.91-unstick-restore/astral.lua?download=1)

В этой версии удалены два исключения, добавленные в v4.90 для собственных защитных предметов. Main.RemoveSticky побайтно совпадает с исходной функцией v4.89. Наша Unstick Aura снова обрабатывает все подходящие предметы обычным способом. Выбор только Unstick сохранён по предыдущему запросу пользователя; другие режимы ауры не возвращены.

AntiKickItems не изменён. Его восстановление после отрыва не является запретом на отрыв под чужой Unstick Aura. В доступных клиентских исходниках нет подтверждённого механизма для такого запрета: чужой клиент отправляет SetNetworkOwner серверу; наш клиент не контролирует серверный обработчик чужого запроса. Этот релиз восстанавливает ауру и не объявляется решением задачи непрерывного крепления.

Для продолжения защиты от отрыва нужен рабочий пример соответствующего механизма либо серверная реализация проверки владения/снятия StickyWeld. Подмена локального weld, скрытие оторванного предмета или ускорение повторного крепления не будут доказательством выполнения требования.

Остальные изменения v4.90 сохранены, включая Remove Food/Desync, Anti Grab, очистку моделей/бластера/заставки, серую тему и магазин. Перед запуском выгрузить текущий Astral через Settings → Unload.

Проверка выполняется командой:

```sh
python tools/verify.py --luau-dir /path/to/luau/tools --analysis-dir /path/to/logs
```

Это CLI-проверки и имитация движка. Живой Roblox и чужая аура не запускались. Лицензии и исходные уведомления сохранены.
