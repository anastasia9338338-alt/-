# Astral v4.85

[Скачать ZIP с Lua](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.85-shop-pcld-ownership/astral.zip?download=1) · [Lua отдельно](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.85-shop-pcld-ownership/astral.lua?download=1)

Выгрузите предыдущую версию через **Settings → Unload astral**, затем запустите новый Lua. Магазин включается в **GUI → Магазин по референсу**; сохранённая конфигурация может содержать выключенный переключатель. Силуэт персонажа: **Visual → PCLD Style → Avatar**. Другие разделы Astral, серая прозрачная тема, иконки и ватермарк сохранены.

Изменения магазина относятся к штатному игровому инвентарю: компактные верхние плашки, десять колонок игрушек, небольшой боковой ряд и Toy Limit. Новая версия обрабатывает вложенные раскладки и контейнеры изображений. Оригинальные кнопки, категории, избранное и их обработчики сохраняются.

Avatar ПЦЛД использует размеры частей персонажа 1:1 и тот же кадр движения, что Box. Физические соединения копии, включая отдельный класс WeldConstraint, удаляются до её появления в Workspace. Части закреплены, не сталкиваются и не участвуют в касаниях или запросах. Прозрачность применяется к самим частям копии, а также к Highlight; невидимые исходные части остаются невидимыми.

Ownership-захват в Kick требует одновременно метку владельца и физический ownership. Наличие одной метки больше не завершает получение физического управления. Цикл использует наблюдение фаз владения вместо слепого чередования Grab/RNO каждый кадр: при пакетной доставке запросы больше не должны систематически схлопываться в одну конечную команду. Быстрая настройка EKI выполняется только после физического подтверждения владения, отдельного кадра симуляции и достижения позиции удержания; старый режим сохраняет прежний таймер. Скорость серверного кика не измерялась.

Проверки запускаются на точных Lua и ZIP. Они включают отдельные воспроизведения вложенного магазина, внешних соединений копии и несовпадения метки/физического ownership, а также существующие регрессии. Это CLI-проверки и имитация движка; живой Roblox, совпадение скриншота по пикселям и серверное время кика здесь не измерялись.

```sh
python -m pip install 'Pillow>=10.2'
python tools/verify.py --luau-dir /path/to/luau/tools --analysis-dir /path/to/logs
```

Исходные лицензии и уведомления сохранены в Lua, включая кодеки [Picguin](https://github.com/wizevaxel/picguin/tree/c9c10f5639720d7dedc7955052026d6636b3d5b0) и [lua-img-ascii](https://github.com/tiberium/lua-img-ascii/tree/822915dd0cc1d72280a018dde0a622fe59fa696b).
