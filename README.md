# Astral v4.83

[Скачать ZIP с Lua](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.83-shop-frame-fixes/astral.zip?download=1) · [Lua отдельно](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.83-shop-frame-fixes/astral.lua?download=1)

Перед запуском выгрузите v4.82 через **Settings → Unload astral**. Предыдущая версия должна восстановить изменённые ею свойства игрового меню.

В игровом магазине переделана именно раскладка: отдельная полоса категорий сверху, боковые игровые иконки, полупрозрачная серая карточка и плотная сетка до десяти колонок. Непрозрачные подложки у отдельных игрушек убраны. На узком экране колонок меньше. Используется существующее игровое меню и его кнопки; пути объектов, картинки, порядок предметов, избранное и игровые обработчики сохраняются.

Оформление применяется только к `MenuGui.Menu.TabContents.Toys` и страницам игрового магазина. При переходе в Settings восстанавливаются размеры и оболочка общего игрового меню. HSV-поля, палитра, градиенты и прочие настройки больше не перекрашиваются. Замена меню после возрождения обрабатывается повторно; отключение оформления и выгрузка восстанавливают изменённые свойства.

Рамка декодируется и собирается в обычный PNG-файл на клиенте. Для PNG и обычных RGB/серых JPG, в том числе progressive JPEG, **не требуется EditableImage или ImageContent**. Созданный файл регистрируется тем же `getcustomasset`, которым загружаются пользовательские картинки. Удаление шахматной сетки, прозрачная середина и скруглённый внешний контур выполняются до вывода. Рамка не уменьшает содержимое окна. Файлы удаляются при замене/очистке/выгрузке. Для прямых ссылок нужны доступные в среде запуска файловые функции; PNG ограничены 4 Мп, JPG — 1 Мп. Декодирование иных форматов оставлено штатному API, если оно доступно.

В Keybinds скрыт скроллбар, исправлен расчёт высоты с учётом внутренних отступов и ограничено содержимое панелью. На узком экране ширина уменьшается. Прокрутка колесом или касанием остаётся доступной.

Серая палитра Astral, исходные иконки и ватермарк сохранены. Встроенные игровые функции этого обновления не менялись.

Проверено: точный bundle и ZIP, компиляция 96 исполняемых модулей и встроенного кода, существующие регрессии, нативный GUI в имитации движка, сохранность HSV-настроек, переключение страниц и возрождение магазина. PNG/JPEG декодеры и полученные PNG дополнительно сверяются с Pillow; в интеграционной проверке EditableImage намеренно запрещён. Анализатор запущен и его сообщения рассмотрены, включая ограничения типов при динамической загрузке модулей. Живой клиент Roblox здесь не запускался; точное совпадение скриншота в клиенте не заявляется.

```sh
python -m pip install 'Pillow>=10.2'
python tools/verify.py --luau-dir /path/to/luau/tools --analysis-dir /path/to/logs
```
