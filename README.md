# Astral v4.95

В архиве `astral.zip` один готовый `astral.lua`. Перед заменой выполнить Settings → Unload astral.

Основной GUI оформлен по BetterOrion, используемому в предоставленном TheWorst: окно 600×400, шапка 50 px, боковые вкладки с названиями шириной 120 px, две колонки, Gotham, строки 38 px, checkbox 24 px и ползунок с заливкой 26 px. Сохранены Astral, функции, ID настроек, привязки, картинки/рамка и watermark. Изменение ширины панели и размера окна остаётся доступным. Устаревшая геометрия прежнего GUI не загружается поверх нового профиля; прежние стандартные цвета/размеры ползунков мигрируют, пользовательские значения сохраняются.

Режимы Kick:

| Режим | Поведение |
| --- | --- |
| Normal | Порядок и время ownership запросов прежнего Faster v4.94; базовая частота контактов сохранена |
| Faster | Та же пара Grab/Release перед и после физического шага; удвоенная частота попыток контакта, без смены рабочей палетки/вращения/удержания |
| Super Fast | Отдельный режим по наблюдаемому движению из ролика: одна настоящая доска помещается у поднятой цели, исходный mover тянет её вверх; следующий физический контакт не начинается до наблюдаемого выхода и восстановления игрового ragdoll |

Loop MS по-прежнему задаёт полный ownership цикл и действует во всех режимах. При потере ownership, отмене/respawn/unload и смене режима дополнительные фазы прекращаются. Super Fast не двигает чужую сборку без physics ownership и не создаёт новые доски для каждого удара. Зависший физический выход отменяется с освобождением общего канала. Игровой Ragdolled только читается.

Видео пользователя скачано и изучено по кадрам: общий ход с шагом 0,5 s и участок контакта с шагом около 0,067 s. Это наблюдение видимого движения, а не извлечение исходного скрипта. В ролике есть переходы между сценами; он не даёт доступа к серверной логике кика. Время 4–6 секунд не заявляется подтверждённым для Astral.

Проверки точной Lua/ZIP включают компиляцию, API/dependencies, сравнение Normal с неизменённым controller v4.94, раздельные физические фазы Faster, Loop MS, физический выход/отмену Super Fast, lifecycle палетки и GUI/settings. Это CLI/engine mocks: live Roblox/executor и серверное время кика здесь не проверялись.

```sh
python tools/verify.py --luau-dir /path/to/luau/tools --analysis-dir /path/to/logs
```
