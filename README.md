# Astral v5.01 — перенос из message.txt

Основа этой сборки — предоставленный `astral(6).zip`, версия **v5.00**. Предыдущие незавершённые изменения из переписки повторно не применяются. Готовые файлы сборки — `astral.lua` и `astral.zip` в корне репозитория.

В сборке сохранены 92 исходных модуля и все 666 найденных постоянных идентификаторов элементов управления. Настройки и функции пользовательской версии остаются на своих вкладках. Контроль исходной версии: [transfers/user-v5-base.json](transfers/user-v5-base.json).

GUI использует встроенные рендереры Obsidian из библиотеки, указанной в `message.txt`: окно 650×500, начальная компактная боковая панель, исходные элементы управления и оформление. Название остаётся Astral. Сохранены фотографии предметов, выбор игроков, привязки клавиш, настройки шрифтов, ползунков, прозрачности, фона и рамки. Внешний Lua GUI при запуске не скачивается. Obsidian ограничивает переданное значение CornerRadius=100 фактическим радиусом 20.

`Target → Loop → Ragdoll` заменяет прежнее название Pallet Ragdoll. Используется спуск из TXT: восемь положений от точки на 10000 studs выше цели, скорость вниз −9997, скорость в точке воздействия −10, затем возврат наверх. Палетка принадлежит одному контроллеру; смена цели, выключение и смена персонажа прекращают старую работу. Число размещений не считается числом серверных попаданий.

`Target → Kick Settings → Remove Anti Kick` использует операцию из TXT: SetNetworkOwner → CreateGrabLine → 0,05 с → DestroyGrabLine для предметов цели в радиусе 5 studs. Blobman и указанные в источнике тракторы исключены. Та же операция подключена к существующему Destroy Anti-Kick. Канал захвата освобождается при отмене; локальное удаление чужих сварок не выдаётся за серверное снятие защиты.

**Режимы кика:**

- Normal сохраняет прежний цикл владения и восемь стадий спуска.
- Faster (Fast Kick) использует период полного прохода палетки **0,10 с**.
- Super Fast использует период **0,06 с** и снова выполняет цикл Grab/Release после захвата. Прежний путь переходил в одно удержание.

Контакт и выход разделены кадром физики. При низком FPS частота ограничивается реальными кадрами; после задержки не отправляется очередь пропущенных ударов. Старое удержание и подтверждение владения не подменяются таймером. В коде нет таймера, который объявляет игрока кикнутым после 10 или 6 секунд. Эти сроки зависят от сервера, задержки и реальных попаданий и не подтверждены локальными тестами.

Сборка и проверка:

```sh
python tools/build_transfer.py
python tools/verify.py --luau-dir /path/to/official-luau-tools --analysis-dir /tmp/astral-analysis
```

Проверяются точный Lua, все исполняемые модули, вложенный исходник, связи контроллеров, сохранность пользовательской базы, реальный код GUI в имитации API, стадии и интервалы палетки при разном FPS, порядок снятия anti-kick, остановка, смена персонажа и выгрузка. Содержимое `astral.zip` должно побайтно совпадать с `astral.lua`. Это CLI и моделируемые проверки, а не запуск Roblox и не доказательство серверного кика за указанное время.

Сведения об авторстве и лицензиях пользовательской сборки сохранены в модуле Notices. Происхождение переноса: [transfers/README.md](transfers/README.md).
