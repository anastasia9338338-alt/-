# Astral v4.79

[Скачать Lua](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.79-blobman-fixes/astral.lua?download=1) · [Скачать ZIP](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.79-blobman-fixes/astral.zip?download=1)

Сохранены серое прозрачное окно, прежние иконки и ватермарк v4.76. Усилен контраст только меню выбора и панелей настроек, исправлен значок изменения размера. В Game Tweaks остались линия и дыра.

- Магнит заменён на переданный пользователем способ: персонаж следует за захваченной деталью под ногами с отступом 3.5 studs, сохраняя поворот. Z по-прежнему отвечает за телепорт; клавиша магнита выбирается отдельно. Магнит отпускает персонажа при отключении, смерти, посадке, респавне, удалении детали или другом активном перемещении.
- Anti Blobman больше не подменяет RootAttachment. Защита от захвата использует существующий CreatureDrop и настоящий захватывающий weld. Руки скрываются локально с сохранением детекторов для защиты; их серверное удаление не заявляется.
- Anti Blobman Aura и Banana Aura сохраняют настоящую корочку, даже если функция еды вернула nil. Аура касается корочкой ноги сидящего игрока, банановый режим затем вращает её внутри Blobman. Эти функции не используют общий паллет для кика и не перемещают своего персонажа. Перемещение корочки разрешено только при подтверждённом владении её физикой.
- Добавлены выход из Blobman кнопкой Leave Blobman и выход прыжком при обычной посадке. Auto Sit отключается при выходе и отменяет уже запущенное задание посадки. Во время полёта Space сохраняет управление высотой; кнопка выхода работает и там.
- Anti Explore не записывает CFrame, скорость, WalkSpeed, HipHeight, состояние Humanoid или суставы. Восстановление через существующий игровой вызов ограничено тремя попытками на новое падение возле опасности и приостанавливается при захвате/посадке/Anti Grab. Ноги сохраняются.
- Server ESP [PCLD] получил выбор Box / Avatar. Avatar повторяет текущий скин и позу на реальной реплицируемой позиции PCLD, учитывает сглаживание; цвет заливки и обводки выбирается отдельно. Копии закреплены, лишены поведения, столкновений и касаний, удаляются при отключении, смене режима, выходе игрока или респавне.
- Item ESP дополнен обнаружением загруженных шаблонов/магазина и новых предметов в SpawnedInToys, обновлением выбора и режимом All Shop Items. Существующие изображения сохранены; изображения неизвестных предметов берутся только из реально загруженного магазина.

Перед запуском выгрузите предыдущую версию через Settings → Unload astral.

Проверки: компиляция всего bundle, 85 исполняемых модулей и встроенного кода; проверка зависимостей и вызовов контроллеров; сценарии захвата/отключения/респавна, магнита, PCLD, магазина и GUI; точное совпадение Lua внутри ZIP. `luau-analyze` проверяется отдельно: без определений Roblox/executor он сообщает об отсутствующих встроенных типах и глобальных именах; это не чистая проверка типов Roblox.

Живой сервер Roblox в этой среде не запускался. Сценарные проверки используют имитацию движка и не подтверждают серверный ragdoll, успешный kick или силу физического броска Blobman.

```sh
python tools/verify.py --luau-dir /path/to/luau/tools --analysis-dir /path/to/logs
```
