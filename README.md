# Astral v4.93

[Скачать ZIP](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.93-physical-hold-shop/astral.zip?download=1) · [Lua отдельно](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.93-physical-hold-shop/astral.lua?download=1)

Перед запуском: Settings → Unload astral, затем выполнить новый Lua.

В этой версии переработана физическая реализация основного кика. Частота ownership requests, выбранные Faster/Normal последовательности, пределы скорости палетки и настройки повторов не увеличивались.

* Одиночная цель располагается точно над текущими X/Z персонажа на выбранной Kick Height; прежний боковой offset убран. Для нескольких целей сохранено расположение в пределах native grab range.
* Первичное подтверждение ownership теперь отделено от устойчивого удержания. Пока реальное тело не достигло области BodyPosition, refresh-release не отпускает capture. При выходе тела из области удержания release приостанавливается, отсутствующий marker запрашивается заново с прежней частотой, а цель mover продолжает обновляться каждый solver update.
* Основной kick больше не использует SourceContact для вызова touch у стоящей в стороне палетки. Он направляется в физический worker: отдельная постановка вне hitbox, вход через реальную скорость, наблюдаемый Touched/пересечение, выход перед повтором и чтение игрового Ragdolled.
* Native WeldHRP, Motor6D и ragdoll constraints цели сохраняются. Убрана ежекадровая перестановка частей тела и обнуление их скорости. Подавление столкновений не сбрасывает CustomPhysicalProperties; новые collider-парты учитываются для корректного восстановления.
* Для первого рагдолла разрешён один изолированный физический проход после реального capture, даже если тело ещё не поднялось. До устойчивого воздушного удержания серии не запускаются. Поздний игровой ответ учитывается перед повтором. Постановка доски учитывает фактическую скорость движущейся цели.
* Общий native ownership channel уступает только фактическому проходу палетки через receiver; во время пауз/восстановления worker его не удерживает. Удерживающий mover продолжает следить за персонажем.

Магазин: исправляются поздние native перезаписи размеров ячеек, промежутков, UIScale/aspect/min constraints. Исправление затрагивает изменённые свойства и не запускает полное оформление магазина на hover/взаимодействии. Структурный кеш, картинки, исходные callbacks, размеры окна, серая тема и QuickSpawn сохранены. Закрытие/повторное открытие и обновление счётчика не требуют повторного оформления всей коллекции.

Проверка выполняется на точных Lua/ZIP: компиляция, API/dependencies и mocked engine regressions для физического входа/выхода, начального capture, удержания/срыва/восстановления, native rig/mass, отмены и lifecycle, исходных методов, магазина и GUI.

Живого Roblox/executor здесь нет. Успешное отключение игрока быстрее 10 секунд, серверное принятие ударов и реальные FPS не измерялись; локальный контакт не объявляется подтверждением кика.

```sh
python tools/verify.py --luau-dir /path/to/luau/tools --analysis-dir /path/to/logs
```
