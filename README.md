# Astral — обновлённая версия

Готовый самостоятельный Lua-файл: [astral.lua](astral.lua). Для скачивания откройте файл и нажмите **Download raw file**.

- Тёмный GUI с округлыми панелями, синими ползунками и белыми бегунками; фоновая картинка отключена, включая сохранённые темы.
- Функции, их имена, идентификаторы настроек и модули иконок сохранены.
- Подтверждённая владением и не занятая сиденьем цель однократно ставится в позицию удержания над персонажем. Затем работают существующие удерживающие компоненты.
- Автоматическое снятие Gucci пропускает удерживаемую цель и перепроверяет условие после ожиданий. Остальные цели обрабатываются независимо.
- Loop Kill, Banana Kill и другие функции остаются отдельными; автоматически они не включаются.

Видео использованы как визуальный ориентир. Точный внутренний алгоритм стороннего Faster Kick по видео восстановить нельзя. Работа на живом сервере Roblox не проверялась.

Проверки: компиляция файла и исполняемых модулей Luau; 225 проверок логики; 19 проверок методов ползунка; 5 проверок отмены нативных операций; проверка отключения фоновой картинки и сохранности идентификаторов элементов управления. Это изолированные проверки, а не доказательство частоты успешных ударов или отключений игроков на сервере.

Оригинальные сведения об авторстве и лицензиях сохранены внутри Lua-файла.
