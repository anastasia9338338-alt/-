# Astral v4.48

**[Скачать готовый ZIP](https://github.com/anastasia9338338-alt/-/raw/refs/heads/main/astral.zip)**. Внутри один готовый `astral.lua`. Исходник: [astral.lua](astral.lua).

Перед запуском выгрузите предыдущую версию через **Settings → Unload astral**. После запуска на Home должна отображаться **v4.48**.

По просьбе пользователя кик заново собран на основе загруженного `astral_v4_43.lua`. Возвращены исходные BodyPosition/BodyGyro, обработка WeldHRP и частей тела, прямой Grab для ближней цели, штатный SNO для дальней цели и исходный порядок Grab → отложенный RNO → следующий Grab. Добавленная в последних версиях схема ожидания подтверждений и отдельного удержания удалена из пути кика и палетки.

Ускорено локальное обновление: удержание и части тела обновляются перед физическим кадром, а палетка в автоматическом режиме ждёт следующий доступный физический кадр вместо 50 мс. Первый запрос палетки запускается сразу. Её нативная механика восстановлена: исходная скорость контакта, движитель, завершение по игровому ragdoll-флагу и исходный предел одной попытки. Постоянные удары по уже включённому ragdoll-флагу больше не подменяют исходный механизм.

Парные запросы Grab/RNO используют отдельный ритм до 60 циклов/с; при высоком FPS отпускание и следующий захват остаются в одном цикле. После зависания кадра пропущенные запросы не проигрываются очередью. Это предел отправки нативных циклов, а не ограничение FPS или частоты локального обновления палетки. Скорость отключения игрока сервером не измерена и не гарантируется.

Сохранены исключение удерживаемой цели из снятия Gucci, отмена и восстановление после остановки/респавна, все конструкции Walker, кокосовые формы, FPV/ракета, физические эффекты, плавный Gucci ESP, Aim и оформление v4.47. Остальные модули не изменены.

Проверки: компиляция итогового Lua, 58 исполняемых модулей и вложенного игрового исходника; 6065 изолированных проверок, включая сравнение порядка действий с загруженным v4.43, частоты при 30–1000 FPS, просадку кадров, захват, остановку, респавн, очистку, ragdoll-флаг, очередь палетки и исключение удерживаемой цели из Gucci. ZIP проверен на совпадение вложенного Lua с итоговым файлом. Это проверки с имитацией Roblox; запуск на живом игровом сервере не выполнялся.

Оригинальные сведения об авторстве и лицензиях сохранены внутри Lua-файла.
