# Astral v4.81

[Скачать Lua](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.81-gui-artwork/astral.lua?download=1) · [Скачать ZIP](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.81-gui-artwork/astral.zip?download=1)

В конце добавлена вкладка **GUI**. Она разделена на две равные колонки: фон и рамка. В каждой находится превью той же высоты и вида, что изображение аватара в Main, и поле для прямой ссылки на изображение или Roblox ID. Вставьте ссылку и нажмите Enter либо выйдите из поля.

Для фона доступны цвет, прозрачность и режим размещения Crop / Fit / Stretch. Для рамки — цвет, прозрачность, ширина, область краёв исходного изображения и режим «Точно под цвет GUI». Этот режим берёт верхний и нижний цвета текущего серого градиента и следует за изменениями темы. Для точного оттенка подходит белая PNG-рамка с прозрачными полями; собственные цвета картинки при тонировании сохраняют влияние на результат.

Рамка автоматически следует за размером окна. Восемь отдельных частей сохраняют углы и рисуют только края; середина не закрывает интерфейс. Для этого не требуется скрытый ContentImageSize или ввод размеров файла. Фон расположен за элементами окна, декоративные слои не перехватывают клики. Кнопки «Убрать картинку» очищают соответствующий слой. Настройки сохраняются обычным SaveManager вместе с конфигурацией Astral.

Пока ссылки пустые, фон и рамка не отображаются. Серый прозрачный GUI, его палитра, иконки, движение окна и ватермарк сохранены без изменений; игровые модули v4.80 не менялись. Перед запуском выгрузите старую версию через Settings → Unload astral.

Загрузка защищена от устаревших ответов и отключения скрипта: старый запрос не заменит последнюю выбранную картинку. Файлы этих изображений сохраняются до замены/отключения, чтобы не удаляться раньше завершения загрузки текстуры. При неподдерживаемой прямой ссылке можно использовать Roblox ID изображения.

Проверено: компиляция всего bundle, 86 исполняемых модулей и встроенного кода; 32 привязки контроллеров; исходные сценарные проверки; 1377 проверок нативного GUI, включая размеры рамки, пустой центр, настройку цветов, превью, восстановление конфигурации, конкурирующие загрузки, очистку и выгрузку. ZIP содержит ровно проверенный astral.lua. Анализатор запущен без определений Roblox/executor; его сообщения об отсутствующих встроенных типах/глобальных именах рассмотрены отдельно.
