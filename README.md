# Astral v4.88

[Скачать ZIP с Lua](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.88-shop-loop-ms/astral.zip?download=1) · [Lua отдельно](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.88-shop-loop-ms/astral.lua?download=1)

Сначала **Settings → Unload astral**, затем запустите новый Lua. Размер магазина сохранён. Тема, градиент и прозрачность игрового меню следуют Astral. Верхняя звезда убрана. Нативные ограничения размеров, нарушавшие сетку, нормализуются; кнопки и обработчики игры сохраняются. Безымянный игровой счётчик обнаруживается рядом с подписью лимита, скрывается и показывается внутри рамки Toy Limit.

Быстрый спавн использует картинку предмета из каталога. Внешняя игровая кнопка может содержать звезду избранного — она больше не принимается за превью предмета. Выбор и бинды сохраняются в обычной конфигурации Astral.

Из Target убраны YouDecoyGucci, отдельные Destroy Gucci/Stop Destroy Gucci, Kick Selected/Kick Server, Add To List, Prepare Pallet/Copy Kick Info, Experimental Kick Improvements и выбор Kick Server Method, показанные в последних обрезанных скриншотах. Auto Destroy Gucci и Enable Kick/Enable Server Kick сохранены. Экспериментальный EKI отключён вместе с его переключателем. Обычные кнопки получили значок нажатия на правом краю; они остаются одноразовыми действиями, а переключатели сохраняют своё состояние.

**Target → Loop MS** содержит переключатель и текущий пинг/период. При включении измеренный Data Ping RTT определяет полный цикл Grab/RNO: половина периода до отпускания, половина до следующего захвата. Период фиксируется на цикл; новый пинг действует на следующий. Удержание и физические проходы палетки работают независимо. При выключенном Loop MS или недоступной телеметрии используется прежний нативный цикл. Физический кадр ограничивает минимальный шаг; это не обещание серверного кика за заданное время.

Проверены точные Lua и ZIP, структура меню, реальные обработчики кнопок, конфигурация, физические кадры, полный цикл Loop MS, отмена, смена персонажа и выгрузка. Это CLI-проверки и имитация движка. Живой Roblox, пиксельное совпадение и фактическая скорость серверного кика здесь не проверялись.
