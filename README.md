# Astral v4.86

[Скачать ZIP с Lua](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.86-shop-kick/astral.zip?download=1) · [Lua отдельно](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.86-shop-kick/astral.lua?download=1)

Сначала **Settings → Unload astral**, затем запустите новый Lua. Оформление магазина: **GUI → Магазин по референсу**. Прочие разделы Astral, прозрачная серая тема, ватермарк и Avatar ПЦЛД сохранены.

Магазин размечен по последнему компактному референсу: закруглённый боковой ряд, полная полоса категорий и отдельная звезда, десять колонок, маленький Toy Limit. Убираются дублирующие локализованные подписи и старое оформление лимита. Изменения сохраняют исходные игровые элементы и обработчики.

В ownership-кике восстановлен нативный цикл запросов. В v4.85 ожидание смены PartOwner замедляло повторные операции, хотя DestroyGrabLine и SetNetworkOwner — отдельные RemoteEvent, а PartOwner не является подтверждением завершения каждой команды. Прежняя проверка, схлопывавшая команды в последнюю запись одной переменной, не доказывала серверное ускорение и больше не используется для выбора рабочего режима. Получение физического владения по-прежнему проверяется отдельно. Реальная потеря физического владения отменяет готовность EKI; штатная смена метки во время цикла не должна разрушать подтверждённое удержание.

Проверки выполняются на точных Lua и ZIP: компиляция, анализ диагностик, UI-сценарии, реальный обработчик движения Box/Avatar, ownership, отмена, восстановление и выгрузка. Это CLI-проверки и имитация движка. Живой Roblox, визуальное совпадение по пикселям и серверное время кика здесь не проверялись; порог 7 секунд не подтверждён.

```sh
python -m pip install 'Pillow>=10.2'
python tools/verify.py --luau-dir /path/to/luau/tools --analysis-dir /path/to/logs
```

Лицензии и исходные уведомления сохранены в Lua, включая кодеки [Picguin](https://github.com/wizevaxel/picguin/tree/c9c10f5639720d7dedc7955052026d6636b3d5b0) и [lua-img-ascii](https://github.com/tiberium/lua-img-ascii/tree/822915dd0cc1d72280a018dde0a622fe59fa696b).
