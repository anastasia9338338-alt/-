# Astral v4.84

[Скачать ZIP с Lua](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.84-shop-avatar-fixes/astral.zip?download=1) · [Lua отдельно](https://github.com/anastasia9338338-alt/-/raw/refs/heads/codex/astral-v4.84-shop-avatar-fixes/astral.lua?download=1)

Выгрузите предыдущую версию через **Settings → Unload astral**, затем запустите новый Lua. Оформление включается в **GUI → Магазин по референсу**; сохранённая конфигурация может содержать выключенный переключатель. Для силуэта персонажа используется прежний режим **Visual → PCLD Style → Avatar**.

Магазин размечен по компактному скриншоту 364×272: маленькая шапка Your Toys, раздельные верхние плашки, десять колонок, боковые белые иконки и нижняя плашка Toy Limit. Координаты находятся в ShopLayout. На другом разрешении весь макет масштабируется пропорционально. Штатные предметы, категории и избранное остаются игровыми кнопками; изображения игрушек, их порядок, пути объектов и обработчики не заменяются. Белые копии иконок и плашки являются декорациями за штатными элементами. Они следуют фактическим областям нажатия оригинальных кнопок, если автоматическая игровая раскладка сдвигает их.

Контроллер поддерживает TabContents как Folder и Frame, появление списка после загрузки, русские подписи и повторную запись размеров игровым интерфейсом. Новые декорации не добавляются в коллекцию игрушек Contents. При закрытии магазина, переходе в Settings, замене меню и выгрузке лишние слои скрываются/удаляются; общие свойства оболочки восстанавливаются. HSV-настройки и другие игровые страницы не оформляются.

ПЦЛД Avatar больше не масштабируется по высоте детектора. Размеры тела и аксессуаров остаются равными размерам исходного персонажа: R6 не растягивается до высоты Box. Центрирование использует части тела без вспомогательных гигантских деталей; корень скелета определяется по соединению с торсом, чтобы desync-помощник не менял геометрию.

У Humanoid копии отключены EvaluateStateMachine и AutomaticScalingEnabled. Все части копии закреплены, без массы, коллизий, касаний и запросов; свойства защищены от повторного включения. Скрипты, физические контроллеры, инструменты, соединения и прочее активное содержимое копии удаляются. Исходный персонаж и его физические параметры не изменяются. [Документация Humanoid](https://create.roblox.com/docs/reference/engine/classes/Humanoid#EvaluateStateMachine) описывает сохранение внешности при отключённой симуляции.

Движение Avatar берётся из того же промежуточного кадра, который использует нативный Box-ПЦЛД. В основном скрипте у Avatar нет второго RenderStepped с собственным сглаживанием. После обновления Box или Snap копия получает тот же кадр; размеры детектора не влияют на размеры кожи.

Проверки включают геометрию магазина для Folder и Frame, позднюю загрузку, автоматические раскладки, области нажатия иконок, клики штатных кнопок, обновление лимита, Settings, возрождение и выгрузку. Для ПЦЛД проверяются размеры каждой части 1:1, одежда/аксессуары, запрет повторных коллизий, вспомогательный корень и совпадение движения с фактическим обработчиком Main.UpdateSmoothPCLD. Прочие регрессии, обработка PNG/JPG рамок, весь bundle и ZIP проверяются общим инструментом. Иконки Astral, прозрачная серая тема и ватермарк сохранены.

Это автоматические проверки в имитации движка. Живой клиент Roblox, физическое столкновение с игроком и совпадение скриншота по пикселям здесь не проверялись. Анализатор запускается без определений Roblox; его сообщения о встроенных API и ограничениях вывода типов рассматриваются отдельно.

```sh
python -m pip install 'Pillow>=10.2'
python tools/verify.py --luau-dir /path/to/luau/tools --analysis-dir /path/to/logs
```

Лицензии и исходные уведомления сохранены в Lua, включая кодеки [Picguin](https://github.com/wizevaxel/picguin/tree/c9c10f5639720d7dedc7955052026d6636b3d5b0) и [lua-img-ascii](https://github.com/tiberium/lua-img-ascii/tree/822915dd0cc1d72280a018dde0a622fe59fa696b).
